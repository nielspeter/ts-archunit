**One finding dissolved on measurement.** Testing's C1 illustrated the missing file set with "delete the
`rules/hygiene` re-export from `src/index.ts` → four primitives leave, all rows green". Under the manifest
rule that deletion is no longer a loss: `./rules/hygiene` is its own declared subpath, so those four stay
published and green is the right answer. The file set still earns its place — dropping a whole entry point
takes three files with it, and sabotage row 6 reds.

**Finding 17, not built and not deferred.** The rival derivation's disagreement _was_ the finding, and it is
now resolved in the population's favour: `haveFields`, `acceptArgs` and `mustNotEndWith` are in. A standing
row comparing the two populations would need its classification list exported from a test file, and copying
it creates the second source of truth it is meant to prevent. Recorded here rather than filed, because
there is no remaining defect to fix — if the two drift again, that is a new finding with new evidence.

**Sabotage after the fixes:** 9 rows, 8 caught, 1 green-and-correct. One row was written to _stay_ green —
`not`'s overloads swapped, with the union in place — and it went red, exposing a coupling in the fix itself:
the corroborated text came from a different declaration than the classified kind. Fixed by carrying the
declaration that justified the kind. Without that row it would have shipped.
